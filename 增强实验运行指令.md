# 增强实验运行指令

以下命令均在 PowerShell 中执行。

## 0. 进入项目目录

```powershell
cd D:\cv
```

## 1. 分析 train/test 图像差异并生成增强配置

```powershell
conda run --no-capture-output -n yolo_gaiic python scripts/analyze_domain_shift.py --sample-limit 2000 --stats-out analysis/domain_stats.json --config-out configs/domain_aug_rgbt.json --report-out analysis/domain_shift_report.md
```

输出：

```text
analysis/domain_stats.json
analysis/domain_shift_report.md
configs/domain_aug_rgbt.json
```

## 2. 生成新的增强训练集

```powershell
conda run --no-capture-output -n yolo_gaiic python scripts/prepare_rgbt_domain_aug_dataset.py --config configs/domain_aug_rgbt.json --out-dir datasets/gaiic_yolo_rgbt_aug_domain --yaml-out configs/gaiic_yolo_rgbt_aug_domain.yaml --overwrite
```

输出：

```text
datasets/gaiic_yolo_rgbt_aug_domain/
configs/gaiic_yolo_rgbt_aug_domain.yaml
```

说明：该步骤只增强 `train`，`val/test` 复用当前 RGB-T 数据，保证验证对比公平。增强均为像素级变换，bbox 标签位置不变。

## 3. 训练增强版模型

```powershell
conda run --no-capture-output -n yolo_gaiic python scripts/train_rgbt_yolo.py --model yolo11s.pt --data configs/gaiic_yolo_rgbt_aug_domain.yaml --imgsz 640 --epochs 100 --batch 8 --device 0 --project D:/cv/work_dirs --name yolo11s_rgbt_aug_domain
```

输出权重：

```text
D:\cv\work_dirs\yolo11s_rgbt_aug_domain\weights\best.pt
D:\cv\work_dirs\yolo11s_rgbt_aug_domain\weights\last.pt
```

当前基线不会被覆盖：

```text
D:\cv\work_dirs\yolo11s_rgbt\weights\best.pt
```

## 4. 验证增强版模型

```powershell
conda run --no-capture-output -n yolo_gaiic yolo detect val model=D:/cv/work_dirs/yolo11s_rgbt_aug_domain/weights/best.pt data=configs/gaiic_yolo_rgbt_aug_domain.yaml imgsz=640 batch=8 device=0 project=D:/cv/work_dirs name=yolo11s_rgbt_aug_domain_val
```

## 5. 导出验证集 COCO JSON

```powershell
conda run --no-capture-output -n yolo_gaiic python scripts/predict_rgbt_to_coco.py --model D:/cv/work_dirs/yolo11s_rgbt_aug_domain/weights/best.pt --source datasets/gaiic_yolo_rgbt_aug_domain/images/val --split val --conf 0.001 --iou 0.7 --max-det 300 --device 0 --batch-size 1 --out submissions/rgbt_val_aug_domain.json
```

输出：

```text
submissions/rgbt_val_aug_domain.json
```

## 6. COCO 评估

```powershell
conda run --no-capture-output -n yolo_gaiic python scripts/eval_coco_results.py --pred submissions/rgbt_val_aug_domain.json
```
